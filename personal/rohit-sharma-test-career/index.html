Rohit Sharma Test Career

An interactive Streamlit dashboard charting Rohit Sharma's Test cricket career across four phases (2013–2016, 2017–2019, 2020–2022, 2023–2024) with position-wise analysis (Opening · #3 · #5 · #6), opposition splits, and home-vs-away contrasts. Built to reveal the career-defining 2019 opening switch.

01 / What

The Test career, by era and by position.

A multi-section dashboard breaking Rohit Sharma's Test career into four chronological phases and three batting-position regimes. Each phase block reports matches, innings, runs, average, strike rate, fifties, and hundreds — and the year-by-year trend reveals the discontinuity that the aggregate average flattens.

The career-defining moment — 2019, switched from middle-order to opening — pops out cleanly in the phase chart: average climbs from 39 (2013–2016) to 55+ in 2017–2019 after the position change. That's the kind of insight a career-summary stat row hides.

02 / Why

Batting average is a compression artefact.

Rohit's Test career average is one number. But that number is the weighted average of a struggling middle-order phase, a stellar opening era, and a transitional reset. Reporting it as a single value tells you nothing about the trajectory.

This dashboard exists to surface the trajectory — to let a viewer see how an "average" career hides four distinct careers stacked on top of each other.

03 / How

From career data to phase narrative.

01

Curate phase and position tables

Hand-built DataFrames covering 2013–2016, 2017–2019, 2020–2022, 2023–2024 phases — matches, innings, runs, average, SR, 50s, 100s per phase. Plus position-wise breakdown for Opening / #3 / #5 / #6.

pandascurated data
02

Style cards and headers

Custom CSS injected via st.markdown for metric cards, section headers, and a consistent blue accent palette. Each phase gets its own "card" treatment — visual rhythm beats a long table.

st.markdowncustom CSS
03

Plotly trend charts

Phase-wise bar chart showing average + strike rate over time. Stacked bars for 50s/100s. Position-wise scatter or grouped bar to show the opening switch's impact. make_subplots for multi-panel layouts.

Plotly Expresssubplots
04

Narrative sections between charts

Short prose blocks explaining each phase — what changed, what the numbers signal. The goal is a guided read, not a dashboard you have to interpret yourself.

storytelling layout
05

Deploy to Streamlit Cloud

Single-file app.py with all DataFrames bundled. No external data calls. Push to GitHub → Streamlit auto-deploys → public URL.

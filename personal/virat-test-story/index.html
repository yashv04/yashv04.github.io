Virat Test Story

An interactive Streamlit dashboard that tells the story of Virat Kohli's Test cricket legacy through career phases, opposition splits, conditions-by-venue breakdowns, captaincy-vs-non-captaincy contrasts, and a statistical legacy section. Built as a long-form, scrollable analysis — not a stat dump.

01 / What

One career, told as a story.

A multi-section Streamlit dashboard structured as a narrative arc through Virat Kohli's Test career — emergence, peak, captaincy era, post-captaincy adjustment. Each section combines headline stats with charts and short prose: not a table dump, a guided read.

The sections cover phase-wise performance, opposition splits (record vs each team), home vs away vs SENA, captaincy impact on his own batting, and a closing statistical legacy section that contextualises his numbers against contemporaries.

02 / Why

Numbers without narrative miss the point.

Most cricket statistics pages are summary tables — career average, hundreds, fifties — that flatten a decade into one row. A career like Kohli's has distinct phases (the 2014 England struggle, the 2016–2019 peak, the captaincy era, the post-2022 reset) that the aggregate hides entirely.

This dashboard breaks the career into those phases and lets the numbers tell the story chronologically — the way fans and analysts actually remember it.

03 / How

From CSV to story.

01

Build career-phase, opposition, and venue tables

Hand-curated DataFrames from Test career records — phase splits (matches, innings, runs, average, SR, 50s, 100s), opposition splits, home/away/neutral splits, captaincy splits. Source: official Test career data through 2024.

pandascurated CSVs
02

Section layout with custom CSS

Streamlit's st.markdown with injected CSS gives each section its own header style, metric cards, and accent palette. Each phase block reads like a short essay with charts inline.

st.markdowncustom CSS
03

Plotly visualizations per section

Phase-wise bar charts for runs/average/SR over time, radar charts for opposition strength, scatter plots for venue performance, donut charts for shot-type / dismissal distribution. All interactive — hover for context, click to filter.

Plotly Expressgraph_objects
04

Statistical Legacy section

Closing comparative section — Kohli vs his Indian Test peers, vs the global modern Test era. Combines stat cards with a brief written summary that frames the legacy in context, not just numbers.

comparative analysistwo-column layout
05

Deploy to Streamlit Cloud

Free-tier Streamlit hosting. Single app.py with bundled DataFrames — no external API calls, no live data sync. The career is closed-form historical data, so freezing the dataset is the right call.

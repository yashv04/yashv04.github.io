Sports Annotation & Ground Truth Engine

A production labelling system for shuttle, cricket ball, bat, and court annotation. Handles manual and model-predicted data in one interface — the infrastructure every downstream CV system at the company depends on.

What

A web-based annotation platform that lets analysts and ML engineers label sport-specific objects across video frames. Four object types — shuttle, cricket ball, bat, court markings — across two sports.

One workflow handles both manual ground-truth labelling and review-and-correct over model predictions, so the same tool drives dataset creation, benchmarking, and human-in-the-loop retraining.

Why

Every downstream system — ball tracking, shot recognition, biomechanics — needs clean, consistent, sport-aware ground truth. Generic annotation tools weren't built for shuttle visibility under arena lighting, partial bat occlusion, or the frame-rate quirks of broadcast feeds.

Without a purpose-built engine, every CV project would re-invent its own labelling pipeline. With one, we get a single source of truth and the ability to retrain models against newly-corrected frames in days, not weeks.

How
  • Web frontend optimized for frame-accurate point and bounding-box labelling with keyboard-first navigation.
  • Backend hosted on Google Cloud Run for elastic scaling during labelling sprints.
  • Predicted-vs-manual diff view — analysts review model output and correct only where it's wrong.
  • Versioned dataset exports feed directly into the training pipeline.
Difficulties
  • Shuttle visibility — a shuttlecock at smash speed crosses several frames as a blur; labellers need sub-pixel precision tools, not generic boxes.
  • Predicted/manual UX — designing one interface that didn't bias annotators toward accepting model output.
  • Cross-sport reuse — keeping shared infrastructure clean while supporting sport-specific quirks (cricket pitch markings vs badminton court lines).
  • Labelling velocity — every UX decision was measured in seconds per frame, because labels at scale are the real cost.

Flagship Work · Computer Vision

Video-Based
Intelligence Systems

Four end-to-end pipelines built for real sports environments — not benchmarks. Every system handles the constraints that break lab models: fast motion, occlusion, variable cameras, noisy audio. Output is structured for coaches and analysts to act on, not model cards.

Design Principle 01
Sports before modelsDefine the sports question first. Algorithm second.
Design Principle 02
Real-world robustnessEvery system tested against failure conditions, not clean data.
Design Principle 03
Failure analysis as designBreakdown cases drive architecture, not retraining.
Design Principle 04
Decision-ready outputEvery model answers: what does a coach do with this?
Four Core Systems
01
Cricket · Badminton
Ball & Shuttle Intelligence System
Tracking fast-moving objects is foundational for speed estimation, shot analysis, and biomechanics. Naive models fail under high velocity and occlusion. This system doesn't.
TrackNet-Based
Components
  • Frame extraction & coordinate annotation
  • Sport-specific TrackNet fine-tuning
  • Trajectory smoothing & continuity checks
  • Robustness testing on unseen clips
Evaluation
  • Ground-truth vs prediction pixel error
  • Visual overlay of predicted trajectories
  • Failure analysis: blur & occlusion cases
  • Iterative accuracy improvements per release
Insights Enabled
  • Speed & trajectory-based shot assessment
  • Biomechanics & tactical analysis foundation
  • Scalable replacement for manual ball tagging
  • Continuous, frame-wise trajectory data

02
Cricket · Badminton
Shot & Action Intelligence System
Manual shot labeling is slow, inconsistent, and doesn't scale. This pipeline uses 2–3 second temporal clips to classify shot types automatically, enabling tactical analysis at scale.
Temporal Modeling
Components
  • Clip-level dataset creation & labeling
  • Motion & execution pattern feature extraction
  • Multi-class shot classification
  • Confusion & failure analysis for label refinement
Evaluation
  • Classification metrics & confusion matrices
  • Qualitative analysis of visually similar failures
  • Iterative dataset refinement cycles
  • Cross-sport generalization testing
Insights Enabled
  • Automated shot distribution analysis
  • Player profiling by shot selection tendencies
  • Scalable tagging for match & training footage
  • Input layer for tactical modeling systems
Stack PyTorchOpenCVPythonVideo AnalyticsTemporal CV
03
Badminton
Smash Technique & Biomechanics System
Smash quality assessment is subjective and relies on wearables. This video-only pipeline gives coaches objective kinematic data — smash speed, joint angles, execution consistency — from raw footage alone.
Video-Only · No Wearables
Components
  • Shuttle velocity estimation from tracked trajectory
  • Player keypoint extraction for kinematic analysis
  • Frame-wise & attempt-wise motion comparison
  • Consistency scoring across multiple smash attempts
Evaluation
  • Visual verification of trajectories & keypoints
  • Consistency checks across attempts
  • Relative comparison of kinematic trends
  • Coach-validated output formats
Insights Enabled
  • Objective smash speed benchmarking
  • Technique consistency analysis over time
  • Data-driven coaching feedback reports
  • Zero manual intervention, full automation
Stack MediapipeOpenCVPythonPose EstimationKinematics
04
Cricket
Audio–Visual Bat–Ball Contact Detection
Visual-only event detection fails under occlusion and camera cuts. This audio-first system identifies hit/miss contact events reliably in noisy training environments — without needing a clean visual frame.
Audio-First · Multimodal
Components
  • Audio clip annotation & feature extraction
  • Binary hit/miss classification with threshold tuning
  • Clip-level manual validation & error analysis
  • Robustness testing across recording conditions
Evaluation
  • Precision, recall & false-positive rate analysis
  • Cross-environment robustness testing
  • Indoor vs outdoor condition performance
  • Noise floor sensitivity analysis
Insights Enabled
  • Automated shot boundary detection
  • Reduced manual tagging effort in pipelines
  • Improved downstream video analysis reliability
  • Works when visual systems fail
Stack Audio Signal ProcessingPythonBinary ClassificationLibrosa
